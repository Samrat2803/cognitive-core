## 🎯 Problem Identified & Fixed

### **Issue:**
Questions were being generated by the strategist node but were **getting lost** when passing through the analyzer node, resulting in `Questions: 0` in MongoDB.

### **Root Cause:**
The `_analyzer_node` in `lean_investigator.py` (line 728-735) was returning a partial state dictionary that **did not include** the `questions` field:

```python
# ❌ BEFORE - Questions were lost
return {
    **state,
    "entities": new_entities,
    "facts": new_facts,
    "connections": new_connections,
    "anomalies": new_anomalies,
    "hypotheses": updated_hypotheses
    # Missing: "questions" field!
}
```

### **Fix Applied:**
Added explicit preservation of the `questions` field:

```python
# ✅ AFTER - Questions preserved
return {
    **state,
    "entities": new_entities,
    "facts": new_facts,
    "connections": new_connections,
    "anomalies": new_anomalies,
    "hypotheses": updated_hypotheses,
    "questions": state.get("questions", [])  # ✅ Preserve questions from strategist
}
```

## 🔄 How Questions Work

### **1. Strategist Node (Iteration 1)**
```python
# Phase: General Investigation
question = "What are the latest developments in AI regulation globally?"
hypothesis_id = "general"

new_question = {
    "id": "q1",
    "hypothesis_id": "general",
    "question": question,
    "status": "exploring",
    "iteration": 1
}
questions.append(new_question)  # ✅ Question created
```

### **2. Strategist Node (Iteration 2)**
```python
# Phase: Testing Hypothesis h1
question = "Are there specific EU member states showing delays in implementing AI Act rules?"
hypothesis_id = "h1"

new_question = {
    "id": "q2",
    "hypothesis_id": "h1",  # Linked to specific hypothesis
    "question": question,
    "status": "exploring",
    "iteration": 2
}
questions.append(new_question)  # ✅ Question created
```

### **3. Analyzer Node**
```python
# Now preserves questions from strategist
return {
    **state,
    "hypotheses": updated_hypotheses,
    "questions": state.get("questions", [])  # ✅ Preserved
}
```

## 📡 WebSocket Streaming

Questions are streamed to the frontend via WebSocket in two ways:

### **1. Initial Load (Polling)**
`app.py` polls MongoDB and sends the full `questions` array:

```python
# In poll_investigation_updates()
for question in investigation_data.get("questions", []):
    await websocket.send_json({
        "type": "question_discovered",
        "data": {
            "id": question["id"],
            "hypothesis_id": question["hypothesis_id"],
            "question": question["question"],
            "status": question["status"],
            "iteration": question["iteration"]
        }
    })
```

### **2. Real-time Updates**
As the agent runs, new questions are added to MongoDB and picked up by the polling mechanism.
